没有经过验证的预测，就不把分数包装成概率。当前免费版只展示有来源的记录与明确的规则时间。

采集运行记录 ↗

后台目标每 5 分钟采集一次，网页打开时每 60 秒检查更新。免费任务调度与网络缓存可能延迟；离开页面后后台仍可采集，但本版不提供后台推送。服务状态接口仅表示运行情况，不是额度重置数据。超过 15 分钟未成功更新会标为延迟。

哪些工具已经接入真实的重置消息？

目前额外重置消息来自 Codex Resets 第三方公开索引，附原帖链接。Claude Code 与 Cursor 接入的是官方服务状态，不冒充额度重置；Gemini API 提供官方规则的每日配额倒计时；Kimi 尚未接入公开重置源。

是否读取了我的 AI 账户？

没有。网站不接收或保存你的密码、会话凭证、API Key、用量或付费信息。个人时间与关注偏好只保存在你的浏览器。真实个人额度仍应到官方账户页面查询。

Gemini 的倒计时覆盖什么？

只覆盖 Gemini API 的每日请求配额 RPD，按太平洋时间午夜计算，并处理夏令时。它不是 Gemini 聊天套餐的统一时间，也不代表分钟限额、计费限制或项目限制同时解除。官方说明 ↗

需要付费或注册吗？

不需要。当前版本没有支付、购买意向、邮件或短信收集，也没有用模拟事件替代真实数据。先把免费的公开看板做好。
